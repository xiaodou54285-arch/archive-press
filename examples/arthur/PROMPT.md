# Arthur Morgan · 案例思路

`reference.jpg` 来自 [Rockstar 官方文章](https://www.rockstargames.com/newswire/article/ak14o883885888/red-dead-redemption-2-recognized-by-the-steam-awards)。`poster.png` 为借助图像生成工具完成的案例成稿。

参考图提供角色识别、举枪动作和透视关系。成稿保留这些特征，把人物、服装与荒野背景统一简化为平整几何色块。

省略五官，保留宽檐帽、明显的胡须块面、外套和弹带。枪口透视、肩部扭转和斜向色块共同形成张力。暖纸白、朱红和炭黑为主，辅以少量赭黄与灰蓝；成稿去掉文字。

这些是案例的创作意图。具体提示词、参数和迭代方式取决于使用的模型与工具。

本案例位于 `examples/arthur/`，用户默认项目不预装这个角色。第三方游戏素材及角色不在 MIT 代码许可的授权范围内。

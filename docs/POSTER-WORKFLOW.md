# 海报协作工作流

这份文档可直接交给 Codex 或其他支持图像创作的助手。

## 输入

从工作台导出 `*-poster-brief.md`，同时提供对应的参考图。用户可以选择已有 IP、真人乐队、原创人物或纯几何主题。仓库不预装角色名单与海报素材。

## 两次确认

1. 阅读简报和实际参考图。先输出具体构图方案：标题位置、全部人物／道具的相对位置、留白、颜色、质感。明确主体数量。等待用户确认；修改方案后重新确认。
2. 用户确认后，使用当前环境提供的图像生成工具制作。若在 Codex 中使用，应用当前可用的 imagegen 技能，不要假称已经调用不存在的接口。
3. 展示完整成稿并核对：人物和道具是否齐全、标题是否清晰、有没有把主体裁掉、图像是否适合窄屏完整缩放。
4. 用户确认成稿后，将其上传到工作台当前分册，再点击“确认使用这张海报”。随后导入评分并生成网站。

助手需要访问用户图片才能进行图像生成。工作台中的图片仅在本地；下载简报不会自动把图片发送给 AI 服务。请用户主动提供图片，不能把“已上传工作台”当作“已发送给 AI”。

## 输出建议

- PNG、JPEG 或 WebP，每张不超过 4 MB，建议横幅 3:2，至少 1536×1024。
- 采用暖纸白、单个强调色与炭黑；参考真实构成主义刊物的比例和动势。
- 海报整体是一个构图，不要机械地给每个标题配一个图标。
- 题字尽量使用简洁中文；保留字体清晰度。没有合适文字生成能力时，成稿留出标题区，再用设计工具排字。
- 参考已有 IP 仅是用户创作选择；公开示例使用原创几何构成。

## 网站接入

音乐与动画游戏各自独立确认，不把一册的海报自动套用到另一册。海报不使用 cover 裁切；窄屏完整缩放。参考图不进入导出的网站。变更主题／参考图后，既有海报的确认状态失效，需再次核对。

# 创作思路与视觉方向

Archive Press 提供一条从兴趣到文化档案的思路：选作品与人物，收集参考，形成个人化海报，再将来源网站的评分与收藏编成目录。

## 图像语言

- 用角色的标志性轮廓、服装和姿势保持识别；简化五官时，也应保留帽子、胡须等关键特征。
- 人物、道具与背景采用一致的平整色块，让整个画面共享抽象语言。
- 用不对称构图、斜线、几何形状和留白建立张力。文字可以参与构图，也可以完全省略。
- 暖纸白、炭黑与少量强调色形成刊物感，纸张和印刷质感保持克制。
- 海报表达个性，密集的数据目录保持清晰易读。

具体怎么生图、使用什么模型、如何组织提示词，由使用者选择的工具决定。工作台记录主题、参考图与风格意图，并接收最终海报。

## 从视觉到数据

每个分册可以有自己的主题和海报，整体共享一套排版语言。图像承担封面表达，搜索、筛选、排序和详情承担档案阅读。

评分尺度与未评分语义来自用户接入的网站。AOTY、Bangumi 是来源预设；也可自定义满分、0 的含义和整数规则。分册类别不决定评分制度。
